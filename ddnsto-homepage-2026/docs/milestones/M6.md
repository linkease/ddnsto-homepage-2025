## 任务与实现

开始前已输出：内容页及内部链接 → 元信息与结构化数据 → 索引/站点地图/404/旧 URL 方案 → 无 JS 和已有模块回归。

- 首页功能区替换占位，四个场景页说明准备条件、流程及边界，十八个设备页复用 M4 的步骤和版本说明。23 个正式路由有唯一主标题、标题和描述，正文不等待 JS。
- 首页功能卡和指南列表提供真实链接；场景页跳到对应演示锚点，设备页回到指定平台；子页客服帮助和活动正确返回首页目标。
- SiteLayout 输出 OG/Twitter 分享信息；本地 share.png 为 1200×630 品牌排版，无第三方资源依赖。
- 生产可索引页面输出去查询/片段的 canonical、WebPage/WebSite 及子页 BreadcrumbList，清单与 sitemap 一致；404 保持 noindex 且不进入 sitemap。
- 预览全部 noindex,nofollow，robots 禁抓取，不泄露 preview.invalid 或模拟生产域名。HTTPS 域名校验拒绝路径、凭据、非法协议及缺失值。
- 未发布 FAQ/Product 评分或活动有效期结构化信息，避免把未经提供的商业信息写成事实。
- 旧 URL 迁移及静态宿主 404 约定见 [SEO-PUBLISHING](../SEO-PUBLISHING.md)。未知旧地址不擅自批量跳首页，不接管控制台 /app/。
