# M4：设备选择与安装指南

2026-11-18，用户明确指令“进入 M4”。任务树与验收标准已在开发前输出，执行范围沿用 MILESTONES 的 M4。本阶段不执行 M5，不操作原 6002 服务。

## 实现范围

- 18 个设备入口，保留参考的路由器与 NAS / 电脑与通用环境分组。
- 5 类设备的 11 个版本选项：ASUSGO ≥386 / <386、LEDE ≤2.3.7 / ≥3.2 / 其他、OpenWrt DDNSTO / DDNSTOX、群晖 DSM 7 / 6、Linux AMD64 / ARM64。
- 57 个步骤面板，原生按钮切换并保持焦点；换设备和版本回到第 1 步。
- 空、未知设备与版本参数提示并回退，兼容参考的 istoreos 和旧 ASUSGO 链接。
- 场景 CTA 到安装区显示对应意图，不自动替用户猜测设备。
- Linux 命令复制成功提示；权限拒绝或 Clipboard API 缺失时，提供只读文本框、聚焦选中并提示手动复制。
- 静态 HTML 包含全部步骤及官方链接；无 JavaScript 时展开全部设备、步骤和版本约束，隐藏不可用交互控件。

## 内容核实与参考差异

事实数据在 src/content/installation.ts，各平台保存来源与核实日期。27 个最终公开外部地址 HEAD 返回 200，包含官方文档、控制台、安装包目录/下载和安装脚本；详细记录在 [sources.json](m4/sources.json)。官方文档正文另经 GET 阅读。未执行安装脚本、登录、绑定真实设备或进行支付。

- EasePi 官方说明为预装应用；iStoreOS / ASUSGO 说明采用填写令牌并启用。没有把参考的“扫码配置 → 生成域名”当作各固件通用能力，保留四步视觉结构，使用已核实的配置指引。
- ASUSGO 386 分界来自官方支持列表，区别是扩展能力；LEDE 未明确的中间版本显示“其他版本 / 不确定”，不推测支持方式。
- OpenWrt 明确区别 DDNSTO / DDNSTOX；群晖提示 CPU 与 DSM 包匹配，ReadyNAS 引导核对官方 ARM/x86 型号表，不承诺未列出的型号。
- Windows 保留官方公测说明和关闭窗口会退出的提示；极空间补充映射目录说明。
- 参考的 web.toany.net 命令未得到官方来源确认，不进入新站。展示 Linux 官方安装脚本的 HTTPS 地址，curl 使用失败返回参数；脚本正文只读取检查，未运行。说明改为在 Linux 终端运行并按提示输入令牌，不对所有平台承诺通用。
- Docker Hub 链接在本环境返回 403，入口改为可访问的官方镜像安装说明。来源文档中不同平台的镜像版本不在官网中统一硬编码。
- 模拟域名使用 example.com；“界面示意”标识保留，不将示意在线状态当真实设备状态。
- 爱快镜像步骤修正参考模板错误的 DEB 图示；OpenWrt 打开终端/安装步骤采用终端示意图。

## 资源和架构

Installation.astro 输出全部内容，controller.ts 仅选择已有 DOM、处理参数、意图和复制，不调用安装、扫描或远控网络请求。数据与视图分离，简单交互不引入 React hydration。

illustration.ts 从参考 simple-install.js 提取纯 HTML 图示函数并修正示意内容；installation.css 提取 simple-install.css / ui-themes.css / site.css 中实际生效的 minimal 样式，限定 #devices 作用域。未整体加载参考脚本。

当前有效设计稿使用 HTML/CSS 界面示意图，没有在此区块使用旧版 ASUS/iStoreOS 截图。因此本阶段没有新增位图资源，不把未生效的历史截图强加到页面；已有品牌图片继续从本站加载。参考快照哈希、独立性与产物边界测试保持通过。
