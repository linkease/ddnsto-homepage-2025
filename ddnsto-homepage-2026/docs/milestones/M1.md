## 测试环境与重现

Browser plugin not available，使用本项目 Playwright 和 Chromium。Node 22.23.4；当前机器用隔离工具链，不依赖父项目 node_modules。

```sh
npm run reference:capture
npm run validate
npm run test:e2e
```

采集命令自行开启并关闭 127.0.0.1 随机空闲端口的参考服务，路径为 `/v2/?v=install-options-1&ui=minimal`。为固定首屏先不带 hash；场景截图在脚本中选择标签后滚动到 #scenarios。每种视口使用新的 context、reduced-motion，截图 animations disabled。默认输出 /tmp；本次已复制到项目文档中持久保存，后续重跑不能自动覆盖已固定基准。

新工程 E2E 使用 127.0.0.1:16208，测试启动前台 Astro 服务，结束后由 Playwright 清理。常用开发端口 16206 与原参考 6002 无关。
