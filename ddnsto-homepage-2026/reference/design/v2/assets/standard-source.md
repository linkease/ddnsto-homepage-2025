# LinkEase 晴岚设计系统 V1.0

代码候选：1.1.0-preview.1；视觉基线：晴岚办公浅色＋晴岚原版。

项目建议值均为当前合理默认；品牌安全区待品牌方确认。首用浅色，系统主题为显式选项。

[可运行规范与示例](standard.html) · [实际验证记录](evidence/v1-standard/verification.md)

## 01 · 设计原则与范围

晴岚办公：柔白内容、灰蓝环境、清晰层级、细边框、克制阴影、适度磨砂、微立体应用图标。保留已确认 v0.8 原版背景与资产，新增规则服务于一致性，不重新打造整套视觉。

本规范 V1.0 面向公司产品的设计与开发；公共代码候选版本为 1.1.0-preview.1。品牌识别、业务权限、数据格式、平台窗口习惯和独立模块业务模型保持各自身份。

规范及本地可运行示例已经实施；现有 Desktop、其他产品内部的整页迁移按页面渐进进行。规范的完成不代表真实产品全量迁移或用户视觉验收通过。

| 规则 | 明确参数／用途 | 限制 |
| --- | --- | --- |
| 精致来自比例与层级 | 正文 14/22、清晰深灰文字、实体内容区域 | 不能通过降低文字对比度制造精致感 |
| 公共源头 | frontend/src/modules/design-system；完整 manifest 闭包 | 禁止下游复制后自行维护另一套颜色或产品行为 |
| 最小必要改动 | 复用控件、资产与 DesignScope，收敛变量 | 不增加新框架、业务状态机、后端或发布平台 |

示例：文件示例保留现有应用图标语言，浅色与深色共享布局。

常见错误：把主题切换写入业务 API 或切换材质时重挂组件。

## 02 · 品牌与颜色

公司品牌色 #0060FF 专用于 Logo、品牌标识与传播；浅色交互色 #316DCC 专用于按钮、链接和选中指示。深色交互色 #8FB8FF 配 #101820 文字。原 Logo 不批量换色。

基础色值 primitives → light/dark 语义角色 → 组件状态；下方语义表直接从公共源生成，每行包含两主题、用途、配对与限制。色值新增必须先记录场景，再验证实际配对。

普通文字至少 4.5:1；符合 WCAG 大字定义时至少 3:1（24 CSS px 常规或约 18.67px 粗体；不能把本规范 16px 区块标题算作大字）。必要控件边界、图标及状态标记至少 3:1。装饰线、不可操作的禁用控件与品牌 Logo 分别记录，不冒充正文检测。

| 场景 | 配对规则 | 使用限制 |
| --- | --- | --- |
| 复杂或深色背景的 Logo | 标准反白资产，或品牌规范承载底板 | 不得临时改品牌蓝或全图反色 |
| 主要按钮 | accent / hover / pressed + on-accent | 深色浅蓝底不得固定白字 |
| 状态反馈 | 文字 + 图标 + weak surface + 边框 | 同时有标题、形状或文字，不单靠颜色 |
| 只读与禁用 | 只读 text-primary；禁用 text-disabled/disabled-bg | 只读仍可选择与复制，不能降低为禁用 |
| 半透明区域 | 依据最终合成 RGB 检查文字；关键操作使用实体底 | 任意壁纸或未验证基底自动降级 solid |

示例：语义色表可切换主题；按钮展示实际 on-accent 配对。

常见错误：用品牌蓝替换全部交互颜色；用装饰线作为输入框唯一边界。

## 03 · 字体与排版

系统字体优先：Apple 使用 -apple-system/BlinkMacSystemFont 与 PingFang SC；Windows 使用 Segoe UI、Microsoft YaHei；Linux/其他使用 Noto Sans、Noto Sans CJK SC、sans-serif。无需安装或下载字体。中文默认 letter-spacing:0，不用人为加宽正文。

Web 单位 CSS px；原生端按各平台逻辑单位及动态字体适配。font-synthesis:none；缺失 500/600 字重时使用系统最接近可用字重，避免额外字体下载与压缩字形；不得以不确定的字体截图宣称跨平台像素一致。

数字、容量、日期与时长使用 tabular-nums，并明确单位与时区；数字右对齐。代码与需精确比对的路径使用 ui-monospace/SFMono-Regular/Consolas/Liberation Mono。正常文件名仍用正文。品牌传播大标题可有独立表现，但不得套用到业务标题。

font-body=13、font-caption=11、font-heading=18与旧line-height仅保留历史宿主适配，不作为新页面字级；新页面使用type-*与le-type-*语义角色。

## 06 · 组件及状态

下方状态矩阵为适用性契约。按下是按住瞬时状态，选中是操作后保留，焦点是键盘位置；状态必须分别建模。示例中的静态状态卡有明确状态标签，真实控件也响应鼠标与键盘。

## 07 · 加载、空态与结果反馈

上传与复制等示例任务是本地模拟，用来验证交互，不访问设备。未知进度显示正在处理，不显示虚构百分比；确定进度才用数值和语义 progress。刷新保留已有内容；失败保留输入、选择和可重试项。

| 失败恢复 | 错误图标与明确标题，保持原输入和目标路径 | 上传失败：“连接中断，文件尚未上传完成”／重试或取消 |

示例：状态场景切换包含空文件夹、搜索、无权限、离线、加载、部分失败；任务可失败并重试。

常见错误：无权限和断网统一显示暂无数据；失败清空字段；未知进度伪造80%。

## 08 · 明暗、响应式与偏好

主题选择 light / dark / system；首次默认 light，沿用已认可晴岚浅色。选择 system 后由 prefers-color-scheme 决定。宿主持久化显式选择，首帧head脚本在CSS/React之前解析有效主题，避免浅深闪烁。存储不可用时回退 light，不阻断页面。

偏好分开保存：theme、density、material、reducedTransparency；壁纸另存，换深壁纸不改 theme。系统主题监听只在 system 生效；切换更新作用域变量，不重挂业务树，草稿、选择和任务状态保留。跨标签 storage 事件同步。

小于768px侧栏进入可关闭的模态抽屉；小于600px正文16/24、触摸目标44px，工具栏保留上传与更多菜单，表格缩减次要列，详情展示完整字段。320px与200%文本不允许整页横向滚动；必要二维表可区域滚动并提供卡片替代。

| 偏好／场景 | 实际行为 | 限制 |
| --- | --- | --- |
| 明暗 | 所有语义角色独立适配，图片Logo保持原色 | 禁止 CSS filter invert 全局反色 |
| 减少透明 | 有效材质solid，保留原material偏好 | 不改变文件、表单背景或业务状态 |
| 高对比 | 边界加强、实体底；forced-colors使用Canvas/ButtonText/Highlight | 避免强制保留低对比品牌背景 |
| 字体与长文 | 200%文字，长路径和中英混排自动换行 | 没有以固定高度裁切重要文字 |
| 系统动态 | prefers-reduced-motion 关闭位移、缩放和旋转动效 | 加载保留文字及静态标记 |

示例：同一文件页面可切明暗，切密度；浏览器改系统主题实时响应 system。

常见错误：改成深色壁纸便暗化正文；切主题导致表单输入丢失。

## 09 · 动效与可访问性

动效只解释状态或空间变化。共同缓动 cubic-bezier(.2,0,0,1)。减少动态模式使用静态替换，不保留大位移、强缩放或持续闪烁。

模态必须有标题/名称，聚焦首个合适操作或错误字段，Tab限定模态内，Escape按业务可取消规则关闭，关闭回触发器；背景inert。重要动态错误用alert，普通结果用polite status，避免同一内容重复播报。

键盘：Tab/Shift+Tab遍历；Enter激活；Space选择；导航标签方向键+Home/End；文件Ctrl/Cmd+A全选、Shift连续选择、F2重命名、Shift+F10菜单，Escape关闭菜单/取消框选。宿主注册快捷键并避开编辑器输入。示例只在文件区域接管这些键。

useDialogFocus 支持 data-initial-focus="true"，排除隐藏、inert及aria-hidden目标；重命名初始聚焦文件名，错误仍保留关联说明与清晰描边。

| 触发场景 | 时长 / 缓动 / 动作 | 减少动态 |
| --- | --- | --- |
| hover / press | 120ms / standard / 仅颜色边界 | 立即变色，不做缩放 |
| 菜单出现 | 160ms / standard / opacity+最多4px位移 | 瞬时显示 |
| 弹窗打开 | 180ms / standard / opacity | 瞬时显示，焦点逻辑不延迟 |
| 抽屉打开 | 220ms / standard / 横向进入 | 瞬时显示 |
| 页面局部过渡 | 200ms / standard / 内容淡入 | 保留旧内容，瞬时替换 |
| 辅助功能 | 焦点3px/offset2；必要状态有文字与形状 | 屏幕阅读器与实际平台辅助技术还需独立验收 |
| 补充时长 | spinner1000ms线性；Tooltip显示延迟500ms、离开宽限100ms；Toast成功4000ms/撤销8000ms | 全部使用同名motion变量；未知进度保留文字，减少动态关闭旋转 |

示例：可用键盘打开弹窗、循环Tab、Escape关闭并返回原按钮；减少动态后加载仍有文字。

常见错误：动画结束才放焦点；读屏只播报颜色；图标按钮没有名称。

## 10 · 文件产品关键操作

文件操作沿用既有领域、权限和任务契约。规范示例只模拟本地数据，不上传、写入或删除设备文件。真实实现以宿主能力判断操作可用性，不因为示例有按钮便伪造后端能力。

所有关键操作同时有桌面与触摸路径。桌面右键菜单可用，触摸使用每项“更多”按钮；框选从空白处启动，不抢滚动和文本选择。拖放有效与无效都显示图标、目标名与文案。

| 操作 | 交互规则 | 反馈与恢复 |
| --- | --- | --- |
| 单选／多选 | 点击行单选；Ctrl/Cmd切换；Shift连续；复选框独立切换 | 选中勾选+背景，焦点不等于选中；批量工具栏显示数量 |
| 框选 | 仅精确指针从空白区域启动；可视框与选中反馈 | Escape取消并恢复开始前选择；触摸用选择模式 |
| 拖拽上传 | 外部文件可放目标清晰，显示目标名、动作、可否放置 | 不可放 Lock/禁止图标与原因；原内容保留 |
| 拖拽移动 | 内部 MIME/资源身份判断源目标，不能移到自身子目录 | 权限不足、跨卷或冲突按既有能力处理；不把上传当移动 |
| 重命名 | F2/菜单打开；保留原名；空名、非法字符与冲突行内错误 | 不默认覆盖，存在同名时改名/取消；确认后保持项目身份 |
| 只读／权限 | 显示只读标签，保留查看复制；写操作禁用并解释 | 无权限是独立状态，不能伪装空文件夹 |
| 批量操作 | 操作前说明目标与数量，可撤销优先撤销 | 部分失败列出每项原因，仅重试失败项 |
| 上传／下载／复制 | 有真实总量时才百分比；保留目标、文件名与任务状态 | 按实际能力暂停/继续/取消/后台；不支持时解释 |
| 长名／深路径 | 行省略但有完整详情与复制入口；面包屑折叠中段 | 详情保留完整文本与可选择；不能只用悬停title |
| 菜单与危险动作 | 右键/Shift+F10/更多一致；禁用项解释 | 可恢复删除给撤销；不可恢复删除或覆盖给明确确认 |
| 稳定选择布局 | 批量操作区预留同一布局空间；增加选择不能移动框选坐标系 | 窄屏更多菜单包含被收起的新建等必要操作，不能简单隐藏 |

示例：示例有单多选、连续选择、空白框选、拖放允许与禁止、重名错误、部分失败清单、可触摸菜单。

常见错误：批量部分失败按全失败重做全部项；只读文件连名字也灰化不可阅读。

## 11 · 开发使用、映射与迁移

公共底层不引入认证、设备、窗口store或宿主alias。DesignScope、Surface、Button、IconButton、TextField、TextAreaField、SelectField、StatusMessage和useDialogFocus组成有限边界；数据、业务回调与宿主能力仍由产品负责。

Portal保留Context但缺CSS祖先，须再包DesignScope；独立createRoot显式传snapshot，iframe/ShadowRoot同步同一CSS与版本。material变化不能进入请求身份或重挂组件。

当前采用源码同步：manifest 的 version、sourceHash、fileHashes 和完整 files 闭包，包含语义角色与状态契约。sourceHash只代表 tokens源；fileHashes验证每个公有文件，不能只比较token哈希宣称全闭包一致。

密度与材质不增加业务状态机。DesignScope 的 density 明确控制32/36/44px与行高，子作用域及Portal继承；新React根显式传入。开发入口文件与仅导出组件的StandardApp分离，保证React热更新保持草稿与选择。

| 规范 | 代码位置／变量 | 落地方式 |
| --- | --- | --- |
| 品牌/语义/状态 | tokens.json primitives/colors + semantic-roles.json + component-contract.json | 改源数据，再generate/check；不手改生成文件 |
| 颜色与尺度 | tokens.generated.css/ts → --le-* | 所有页面引用语义变量，原生端生成同名平台映射 |
| 实体与材质 | foundation.resolveDesign/materialForRole；Surface role | 宿主持久化偏好及能力检测，公共层纯函数；DesignScope density控制密度，子作用域/Portal继承，独立根显式传入 |
| 主题 | resolveAppearance + 宿主theme bootstrap/storage/media | 有效appearance传DesignScope，wallpaper独立 |
| 字体/间距/圆角/阴影/动效/层级 | --le-type-*、space-*、radius-*、shadow-*、motion-*、z-* | V1.0新页面使用type-body-size，不用legacy13字号 |
| 渐进步骤1 | 锁定公共源版本并记录现有页面/业务基线 | 只同步公共闭包，不在下游改公有行为 |
| 渐进步骤2 | 先接作用域、旧--theme别名和实体角色 | 保持业务状态，验证Portal、iframe、ShadowRoot |
| 渐进步骤3 | 逐整页迁移字级、状态、组件与响应式 | 一个页面验收后上线；不把混合视觉当最终版本 |
| 渐进步骤4 | 同场景明暗/窄屏/长文/状态及真实业务回归 | 其他模块内部各自独立任务，规范完成不等于已迁移 |
| 语义字级类 | le-type-page/dialog/section/body/label/helper/reading | 按视觉用途选择类；不靠h1/h2标签强行改变旧业务页字体，保留HTML语义结构 |

示例：标准页由公共源码独立构建到8302，8023可直接HMR同一 standard.html。

常见错误：只拷CSS一部分；把旧原型探索设置当产品功能；生成文件另行维护。

## 12 · 验收与待验证

验收必须留实际记录：公共生成一致、类型检查、构建、颜色对比计算、浏览器计算样式与合成材质、主题保存/系统/首帧、密度、文件/表单/任务、模态焦点、窄屏/放大及控制台。

自动验证覆盖本规范示例与本次公共控件改动，不能宣称整家公司产品通过WCAG认证，不能用示例代替真实设备写操作回归。最后审美和交互体验仍由用户在页面确认。

待验证边界：Apple/Windows真实字体与原生窗口习惯、真实读屏（VoiceOver/NVDA/TalkBack）、真触摸设备及原生动态字体、全部壁纸采样、其他模块内部迁移、真实传输/后台任务能力与全量Desktop暗色。浏览器模拟只代表相应模拟场景。

| 验收项目 | 通过标准 | 证据 |
| --- | --- | --- |
| 视觉 | 仍为晴岚办公、原Logo不批量变色、同页主题保持结构 | 同视口首页前后、浅深/窄屏截图 |
| 变量 | 色值有角色与配对，尺度有用途，状态无模糊范围 | 公共schema/manifest检查 |
| 交互 | 主题密度状态真实切换，输入选择保持，错误可恢复 | Playwright交互断言与错误日志 |
| 可读性 | 规定配对4.5/3阈值；玻璃在声明基底合成后验算 | 机器报告记录最小值与未验证场景 |
| 迁移 | 每页业务、合同、权限与状态回归；不留下最终中间态 | 后续各产品验收，不能从示例推导通过 |

示例：页面提供规范、交互示例与验证记录入口。

常见错误：仅因代码编译或页面响应200便宣布UI与业务全部验收。
